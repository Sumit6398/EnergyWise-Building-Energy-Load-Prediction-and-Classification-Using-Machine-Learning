# ⚡ EnergyWise: Building Energy Load Prediction Using Machine Learning

## 📌 Overview

**EnergyWise** is a machine learning project designed to predict building heating and cooling energy requirements based on building design characteristics. Using the UCI Energy Efficiency dataset, the project compares multiple ML algorithms, evaluates prediction accuracy, and visualizes actual versus predicted energy loads to support energy-efficient and sustainable building design.

## 🎯 Objectives

- Predict heating and cooling energy loads.
- Compare multiple machine learning algorithms.
- Evaluate model performance using appropriate metrics.
- Visualize actual vs. predicted values.
- Identify important building design features.
- Support data-driven energy-efficiency decisions.

## 📊 Dataset

- **Source:** UCI Machine Learning Repository
- **Dataset:** Energy Efficiency
- **Features:** Relative compactness, surface area, wall area, roof area, overall height, orientation, glazing area, and glazing distribution.
- **Target variables:** Heating Load and Cooling Load.

## 🛠️ Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## 🤖 Machine Learning Approach

The project explores regression algorithms to predict energy loads and compares their performance using evaluation metrics such as:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## 📈 Visualizations

The project includes visual analysis to understand the dataset and model performance, such as:

- Exploratory data analysis (EDA)
- Feature correlation heatmap
- Actual vs. predicted plots
- Model performance comparison
- Feature importance analysis, where supported by the selected model
